# GlowTap Docs

Documentation, specifications, wireframes, and reference assets for the GlowTap platform.

## Contents

- Functional and solutioning specs for Super Admin, Salon Admin, and End Customer portals
- Figma build guides and wireframes
- Brand theme and pricing timeline
- Reference React components for UI patterns

## PDF generation

Install dependencies and generate PDFs from markdown:

```bash
npm install
npm run pdf
```

Generated PDF files are excluded from version control (see `.gitignore`).
